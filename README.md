# ESP32-C3 Portable Thermo-Hygrometer

Portable temperature and humidity monitor based on an ESP32-C3 Super Mini.

The device was designed as a standalone battery-powered prototype with a custom 3D-printed enclosure.

## Project Goal

The goal of the project was to design and build a compact portable measurement device using an inexpensive microcontroller, sensor and recycled battery.

The project combines:

- embedded firmware development;
- sensor integration;
- OLED display control;
- battery-powered operation;
- 3D modeling and printing;
- practical hardware testing.

## Hardware

| Component | Purpose |
|---|---|
| **ESP32-C3 Super Mini** | Main microcontroller |
| **DHT11** | Temperature and humidity measurement |
| **SSD1306 128×64** | Display |
| **Nokia battery** | Portable power source |
| **3D-printed enclosure** | Mechanical housing |

Battery capacity: approximately **800 mAh**.

## Software

**Language:** C++

**Platform:** Arduino

**Main libraries:**

- Adafruit Sensor
- DHT / DHT Unified
- Adafruit GFX
- Adafruit SSD1306
- Wire

### Firmware responsibilities

The firmware:

1. Initializes the DHT11 sensor.
2. Initializes the I²C interface.
3. Initializes the SSD1306 display.
4. Reads temperature and humidity.
5. Displays the measured values.
6. Reports sensor errors through the serial interface and display.

---

## Display Interface

The device uses a 128×64 SSD1306 OLED connected through I²C.

Current I²C pins:

- SDA: GPIO 8
- SCL: GPIO 9

DHT11 data:

- DATA: GPIO 1

## Prototype Results

The prototype successfully performs temperature and humidity measurements and displays the results on the OLED.

During testing several engineering limitations were identified.

### 1. Temperature measurement error

The DHT11 sensor is positioned too close to the charging/discharging circuitry.

The electronics generate heat that affects the measured temperature, causing the displayed value to be several degrees higher than the surrounding environment.

**Cause:** thermal coupling between the sensor and the power electronics.

---

### 2. Slow temperature stabilization

The device was originally intended for quick portable measurements.

In practice, the temperature reading changes slowly and may require approximately **30–40 minutes** to stabilize after a significant environmental change.

This makes the current prototype unsuitable for accurate instant temperature measurement.

---

### 3. Limited battery life

The approximately **800 mAh** battery provides around **20 hours** of operation.

For a portable measurement device, this is lower than desired.

The current prototype therefore provides useful functionality, but still requires optimization of power consumption and hardware placement.

---

## Engineering Lessons

The prototype demonstrated several practical design considerations:

- Sensor placement can significantly affect measurement accuracy.
- Heat generated by power electronics must be considered during mechanical design.
- Sensor response time can become a system-level limitation even when firmware updates the sensor correctly.
- Battery capacity alone does not determine runtime; the complete power budget must be considered.
- A functional prototype often reveals problems that are not obvious during initial design.

---

## Possible Next Revision

Potential improvements:

- Move the DHT11 away from the power/charging circuitry.
- Improve thermal isolation between the sensor and electronics.
- Replace the DHT11 with a faster and more accurate environmental sensor.
- Measure and optimize the actual current consumption of each subsystem.
- Introduce low-power modes when continuous measurement is not required.
- Redesign the enclosure around the thermal behavior of the electronics.
